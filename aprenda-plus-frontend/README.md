# AprendaPlus: Front-end

Interface em **React + Vite** da plataforma AprendaPlus.

A documentação completa do projeto (funcionalidades, como rodar, testes, segurança e decisões de projeto) está no [README principal](../README.md).

## Comandos

```bash
npm install            # instala as dependências
npm run dev            # roda em http://localhost:5173/aprenda-plus/
npm test               # roda os testes (510)
npm run test:coverage  # testes + relatório de cobertura em coverage/index.html
npm run deploy         # publica no GitHub Pages
```
